# SQL Analysis and MCA Final-Year Project

This repository contains two distinct kinds of material: LinkedIn Learning course exercises and an MCA final-year data science notebook. The course exercises are identified and credited below; the notebook is presented as the academic project work.

## MCA final-year project: customer purchase prediction

The notebook `MCA Final Year ROI Data Science Project.ipynb` analyzes customer and travel-product data to explore purchase behavior and compare classification models.

### Notebook workflow

- Inspect and clean the dataset, including missing values and inconsistent categories
- Explore purchase patterns across customer and website-usage fields
- Prepare numeric and categorical features
- Compare Logistic Regression, Random Forest, Gradient Boosting, and XGBoost
- Evaluate models with stratified five-fold cross-validation and a holdout set

The notebook expects a CSV named `AeroReach Insights.csv`. The dataset is not included in this repository; in Google Colab, the notebook prompts you to upload it. Use only data you have permission to share, and do not upload personal or confidential records.

### Run the notebook

Open the notebook in GitHub or Google Colab. Install the packages listed in `requirements.txt` if running locally. Some notebook cells use Google Colab's file-upload interface and may need small changes for a local environment.
